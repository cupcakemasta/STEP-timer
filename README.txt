A customizable study and exam timer with countdown and count-up modes, flexible blocks and breaks, exam presets (CMS, NBME, Full Exam Simulation), accommodations timing, live session logging, recovery after closing/reloading, and optional always-on-top mode on supported desktop browsers.


IPHONE / IPAD APP SETUP

1. Open https://cupcakemasta.github.io/STEP-timer/ in Safari.
2. Tap Share.
3. Tap Add to Home Screen.
4. Tap Add.
5. Launch Study Timer from the new Home Screen icon.

Use the same GitHub Pages URL consistently so Safari uses the same saved timer settings, active-session recovery data, and session logs for that site.

If an older Home Screen copy was installed before these PWA files were updated, remove the old Home Screen icon and add it again after the new files have deployed.
